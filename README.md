## Sylvonix / Sylvonix Engine

Sylvonix is a game engine made using vulkan whitch aims to make the user feel as much in control as possible. As such unlike traditional Engines Sylvonix lets the user initialize the engine and swap out modules.

## Included Modules

There are currently two primary modules:

### Sylvonix Renderer

The rendering module responsible for Vulkan rendering, materials, pipelines, HDR rendering, and graphics systems.

### Sylvonix Core

The core engine module responsible for scenes, physics, entities, and the C# API.
