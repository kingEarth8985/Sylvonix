## Sylvonix / Sylvonix Engine

Sylvonix is a game engine made using vulkan which aims to make the user feel as much in control as possible. As such unlike traditional Engines Sylvonix lets the user initialize the engine and swap out modules with custom ones in case the base functionality of what the official modules use is not enough.

## Included Modules

There are currently two primary modules:

### Sylvonix Native

The native module responsible for Vulkan rendering, materials, pipelines, HDR rendering, graphics systems, input, and the main loop.

### Sylvonix Core

The core engine module responsible for scenes, physics, entities, and the C# API.
